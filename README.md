# KUACON 2027 — Minimal React site

Quick scaffold for the Karnataka conference site. Venue updated to Sirsi and year updated to 2027.

Install and run:

```bash
npm install
npm run start
```

The brochure placeholders live in `public/` (they open in a new tab). Replace those with real PDFs (for example `public/brochure-conference.pdf`) and update links if needed.

Registration payment: stubbed Razorpay integration in `src/pages/Registration.jsx` — add your Razorpay key and enable Checkout script to test payments.
